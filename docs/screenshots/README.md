# 效果图

交互预览截图使用演示状态与示例台词。DSH 桌面实机截图由维护者提供并明确确认已脱敏，按原图使用。

| 文件 | 展示内容 |
| --- | --- |
| `dsh-desktop.png` | 维护者提供的 DSH 桌面客户端实机效果，已脱敏，原样使用 |
| `overview.png` | 桌宠运行总览与工作中状态 |
| `independent-drag.png` | 设置面板与闭眼桌宠独立移动，面板标题支持键盘操作 |
| `custom-phrases.png` | 自定义场景、台词编辑、保存与试说 |

更新交互预览截图时先运行 `npm run check` 和 `npm run preview`，再通过真实界面完成相应操作。可以直接截取相关组件，但不要拼装或重画界面来替代运行效果。交互预览状态由按钮模拟，不作为真实 DSH 任务联动的验收证据；实机截图应标注来源并完成脱敏。
